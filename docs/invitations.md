# ことばの招待状

自由入力の3・4文字を、通信せず復元できるコードにする機能。
通常進行・コイン・デイリー目標・成績には書き込まない。
招待プレイの入力や履歴は一時的で、終了すると破棄する。

## コード v1

5文字ずつの英数字（合計10文字）。Crockford base32で、大文字小文字、
ハイフン・空白、O/0、I/L/1の入力の違いを吸収する。
40bitの本体にバージョン・文字数・乱数・文字データを格納し、CRC-10を付ける。
平文のひらがなを直接埋め込まず、乱数ごとに異なるマスクを使う。
CRCは入力ミス検出用で、署名ではない。コードの解析や意図的な改変、
不適切表現の完全排除は保証しない。サーバー・一般公開の一覧は持たない。
将来形式を変える場合もv1の復元処理を残すこと。

## ヒント付きコード v2

ヒントなしはv1のまま。ヒント付きは `K2.` で始まり、v1の答えコードと
UTF-8のヒントをbase64urlで包み、CRC-32を付ける。大文字小文字は区別する。
40文字は絵文字や結合文字を含め、見た目の文字（grapheme）で数える。
作成・復元の両方でヒントを検証する。ヒントは「ヒントを見る」を押した
ダイアログでのみ表示し、通常のヒント段階や保存処理を使わない。

日本語40文字では約186文字、ASCII40文字では79文字になる。
手入力には長いため、コピーと専用の貼り付けボタンを使う。
配布先URLとAndroid/iOSのリンク連携が用意できたら、タップで開ける
共有リンクとの併用を推奨する。自己完結するリンクは情報量自体を短くする
ものではなく、短縮URLには別途サーバー等が必要。今回はリンクを発行しない。

## 禁止語

`lib/invitation_words.dart` の完全一致リストを更新する。
作成時と復元時の両方で検査する。短い部分文字列を一律禁止しない。
ひらがなの結合濁点・半濁点は合成してから文字数と禁止語を検査する。
登録単語リストには依存せず、固有名詞・造語も受け付ける。
ヒントには同ファイルの明確な不適切表現のリストも使う。
「かたわら」など一般語になる曖昧な断片は部分一致の対象にしない。
ヒントが正解を含む場合は作成画面で警告するが、作成は妨げない。

## 検証

`flutter test test/invitation_test.dart test/invitation_widget_test.dart`

Androidの実操作検証はAPKを `adb install -r` で更新して行う。
保存データがある端末で、アプリを再インストールする結合テストは実行しない。
検証前のバックアップは端末外にも保存すること。

コピー後のLINE・SNSへの貼り付けと送信は利用者が行う。
